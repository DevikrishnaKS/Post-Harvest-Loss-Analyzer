# 🌾 Post-Harvest Loss Analyzer

## 📌 About
Post-Harvest Loss Analyzer is a Python-based Data Science and Machine Learning project designed to analyze and predict agricultural losses after harvesting.

It identifies factors such as storage, transportation, temperature, humidity, pest attacks and physical damage that contribute to crop losses.

## 🎯 Features
- Agricultural data analysis and cleaning.
- Post-harvest loss percentage calculation.
- Machine Learning-based loss prediction.
- Actual vs. predicted loss visualization.
- Loss categorization and recommendations.
- Interactive GUI and dashboard.

## 🛠️ Technologies Used
- Python
- Pandas, NumPy
- Matplotlib
- Scikit-learn
- Random Forest Regression
- Tkinter
